# Trabalho 2 - Algoritmos Genéticos

## Problema

Escolha um problema de seu interesse e construa um AG para encontrar a solução. Pode ser um problema de otimização como o caixeiro viajante, problema da mochila, problema de alocação de salas de aula e professores, ou ainda um puzzle, como jogo dos oito, oito rainhas, sudoku, ou o mundo de Wumpus, etc...

Use alguma biblioteca em python para facilitar o desenvolvimento:

https://pygad.readthedocs.io/en/latest/

https://www.datacamp.com/tutorial/genetic-algorithm-python

https://pypi.org/project/geneticalgorithm/

Entrega: o código fonte e um relatório, descrevendo os detalhes e decisões de projeto: formato e codificação do cromossomo, tamanho da população, detalhamento da função de fitness, critério para seleção, cruzamento e mutação (e as respectivas taxas), critério de parada e plots de execução, mostrando a convergência do algoritmo e melhor indivíduo da população. Também traga suas considerações sobre a implementação, dificuldades encontradas e percepções pessoais.

O trabalho é em grupos (mesmos grupos já montados para o trabalho de Sistemas Especialistas).
