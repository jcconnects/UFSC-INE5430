# Trabalho 1 - Construção de um Sistema Especialista
A construção de um sistema especialista se dá pelo estabelecimento de regras de inferência que relacionam dois ou mais domínios de conhecimentos (doenças, sintomas e tratamentos, por exemplo) .

Na lista 1 utilizamos lógica para modelar a relação entre dois domínios (doenças e sintomas, por exemplo). Para a construção do Sistema Especialista, utilizaremos o conhecimento já adquirido, porém agora modelado em frames. Também integraremos novos conhecimentos de forma a criar uma relação entre pelos menos 3 domínios (agregando os tratamentos por exemplo).

Para tal, busque o conhecimento necessário para o seu tema, construa tabelas que relacionem os domínios e a partir daí extraia as regras em linguagem natural. Use o CLIPS para modelar o sistema em Frames. Também devem ser executados e apresentados testes utilizando situações possíveis (casos) e a "acurácia do sistema" deve ser discutida e apresentada na forma de um breve relatório.

Forma de entrega: Devem ser entregues o sistema implementado em CLIPS e um relatório contendo as tabelas que correlacionam os domínios, as regras em linguagem natural,  os casos apresentados ao sistema e o retorno dado, além da discussão sobre o comportamento do sistema.
